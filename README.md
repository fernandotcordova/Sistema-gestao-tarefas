## ⏯️ Como rodar o projeto?
1. Com visão de facilitar a compilação dos arquivos, é recomendável utilizar uma IDE (Integrated Development Environment), essa pode ser aquela que lhe agrada mais, a exemplos: NetBeans -- a que usaremos --, Eclipse, InteliJ etc.;
2. É essencial que também tenha instalado em sua máquina o JDK (Java Development Kit), em vista de compilar qualquer projeto;
3. Entre na sua IDE favorita para Java e importe todos os arquivos dentro da pasta "src";
4. Pronto 😄 Agora é só testar qualquer projeto e ser feliz!

## 📓 Sistema de gestão de tarefas
- Sob a ótica dos dois outros projetos e seguindo os princípios mencionados anteriormente;
- O arquivo "SistemaDeGestaoDeTarefas.java" é o arquivo que realiza requisições, contendo, assim, o método main;
- O arquivo "Tarefa.java" cadastra as informações relativas as tarefas;
- O arquivo "TarefaDAO.java" concentra a lógica de programação e realiza as operações CRUD.
